# Supporting evidence delivery

Open **Supporting evidence replay** on an Environment Library release. Submit the reviewed JSON, its independently supplied SHA-256, the evidence cutoff in UTC, and the source and admission IDs for `supporting-source-review` `v1`. The service checks current internal-analysis permission and the selected manifest. The offline worker reads the same pinned input.
