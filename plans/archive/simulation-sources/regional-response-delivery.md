# Regional response and coastal recovery delivery

Open **Regional response and coastal evidence** on an Environment Library release and enter the reviewed file, its independently supplied SHA-256 and a UTC evidence cutoff. The source admission must cover `regional-response-review` `v1` and permit internal analysis. Atlas presents published counts at their original reporting grain, authored workload comparisons, and dated coastal evidence. **Historical port activity** uses the separate `imf-portwatch` `daily-ports-v1` admission and accepts user-selected baseline and return settings. The worker supports both workflows offline. ## Rebuild or extend a reviewed package

`prepare_regional_response.py` extracts the two SRCA releases and the MOH workbook, reads land and offshore samples from a pinned coastal release, groups completed-day reception receipts and joins matching dated PortWatch counts. The reception input contains UTC day, an observation window in minutes from midnight, connected minute ranges, and receipt checksums. It preserves reconnect gaps, merges overlapping connected intervals, and records the reception summary and PortWatch counts with separate availability times. Publish the combined historical reception summary only under the applicable source admission. [Preparation commands](../../../scripts/data/prepare_regional_response.py)

The PortWatch fixed comparison uses matching weekdays before the study period. Set the study period, minimum matching weekdays and consecutive recovery days before inspection. Missing days and values outside the historical range break the consecutive run. The validation uses the same observed study dates for both models. It compares the preceding eight weeks of the same weekday, extended if the minimum requires it, with the preceding 28 calendar days, requiring at least 14 observations in that trailing window. All training observations precede the scored date. The reported range is the observed sample minimum and maximum. [Port comparison implementation](../../../internal/geoenv/port_activity.go)

```powershell
$portFile = 'private/environment-foundation/implementation/regional-response-review/port24.json'
$portSha = '1fed7d0b6c05ada9aa47c239c4646dec3f6e3c7a85430ead13867ce9c26e2df0'
go run ./apps/emad-environment replay-port --input $portFile --sha256 $portSha --port port24 --baseline-from 2023-01-01 --from 2024-01-01 --to-exclusive 2025-01-01 --minimum-weekdays 4 --consecutive-days 3
```

`evaluate_coastal_search.py prepare-noaa` emits either the participant study definition or the held-out reference. The evaluator matches completed searches and reported sightings against withheld cell-time pairs, counts each searched cell once and keeps unresolved cases in the denominator. Retain source extracts, the search layout and the reference file in the evaluator's workspace.
